# Manuscrit Pro

Manuscrit Pro est une application web de diagnostic littéraire destinée à aider les auteurs à analyser la structure, la cohérence, le rythme, les personnages, les répétitions et le style de leur manuscrit.

## Fonctionnalités
- Analyse de texte manuscrit
- Détection de répétitions
- Suivi des personnages et lieux
- Diagnostic de structure et de cohérence
- Évaluation du rythme narratif
- Plan de révision personnalisé

## Utilisation
1. Ouvrez `index.html` dans le navigateur, ou
2. Lancez un serveur local :

```bash
python3 -m http.server 8000
```

3. Accédez à http://localhost:8000

## Fichiers
- `index.html`
- `style.css`
- `config.js`
- `analyzer.js`
- `app.js`

## Objectif
Aider les auteurs à améliorer leur manuscrit avant soumission ou publication.
